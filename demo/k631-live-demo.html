How to install your layout in Windows
  1. Click Export Windows layout. Each export gets a new name (v2, v3…), so it never clashes with one you installed before.
  2. In Microsoft Keyboard Layout Creator: File → Load Source File → K631Live\export\K631-custom.klc.
  3. Project → Build DLL and Setup Package, then run setup.exe from the folder it creates in Documents.
  4. Press Win + Space and choose the new French - K631 custom version.
  5. Optional: remove older versions in Settings → Apps → Installed apps.
